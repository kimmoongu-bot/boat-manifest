## 실제 폰 카메라 테스트 순서 (폰이 빌 때, 삼월이가 직접 — Claude 는 허락 없이 이 폰에 adb 금지)
1. PC에서 `node tools/serve.mjs 8123` 실행, PC 크롬으로 `http://localhost:8123/test-qr/` 를 띄워 둔다
2. 폰을 USB로 연결하고 `adb -s R3CM80RH7BH reverse tcp:8123 tcp:8123` → 폰 크롬에서 `http://localhost:8123/captain/` 열기
3. 설정 → 항차 열기 → "QR 스캔" → 카메라 허용 → PC 모니터의 QR 5장을 차례로 비춤 (같은 QR을 오래 비춰도 1번만 등록되는지, 진동·소리)
4. 다른 폰에 손님 QR(`/guest/`)을 만들어 실제 폰 화면 → 폰 카메라로 찍기, 밝은 곳(창가)에서도 시험

## 실제 폰 최종 점검 (배포 뒤, 폰이 빌 때 삼월이가)
1. 폰 크롬으로 배포 주소 /guest/ → 정보 입력 → "홈 화면에 추가" → 아이콘·이름 "승선QR" 확인
2. 다른 폰(선장)에 /captain/ 설치 → 아이콘·이름 "승선명부 선장" 확인, 배 정보·선장 입력
3. 선장 폰 "QR 스캔"으로 손님 폰 화면 QR 찍기 — 진동·소리·이름 표시, 계속 비춰도 1번만 등록
4. 야외 햇빛 아래(손님 화면 밝기 최대)에서 같은 스캔, 거리 20~40cm·각도 바꿔 보기
5. 코팅한 안내문 QR을 일반 카메라로 찍어 /guest/ 가 열리는지
6. 신분증 확인 → 명부 확정 → "PDF·엑셀 보내기"로 카톡(PC로 나에게)·메일 보내기, PC에서 PDF·엑셀 열어 한글 확인
7. 엑셀이 공유 목록에 안 뜨면 다운로드 폴더에 저장됐는지 확인
8. 비행기 모드로 두 앱 다시 열기 → 열리는지, 스캔·확정·PDF 만들기까지 되는지
9. (가능하면) 아이폰 사파리에서 손님 QR 만들기·홈 화면 추가
